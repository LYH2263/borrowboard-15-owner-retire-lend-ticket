# Borrowboard · 邻里借用

上架 → 借出通过 → 归还；单物件同时仅一笔在借，含逾期判定。

| 服务 | 端口 |
| --- | --- |
| 前端 | 5400 |
| API | 10400 |

0-1：`deposit` / `damage_note` / `neighbor_rating`。

## 户名合并（物主页）

把旧名并入存续户名（如「李四」→「李四家」），署名规则写进同一个合并提交：

- 提交内把旧名下物品**改写成新户名**（在借行物主随之显示新户名），并登记
  `旧名 → 新户` 别名（`owner_aliases`），支持链式折叠。
- 此后**新上架只认新户名**：再用旧名上架自动改记为新户（响应 `rewritten_from`），
  旧名不得重新立户。
- 可借栏物主列、物主一览人数、借还记录、顶细条物主筛选，一律按合并后的户聚合，
  旧名不再单列。
- 合并**不改写**任何借用字段，`loans.due_date` 原样保留。
- **空户名（种子脏数据「无主」）永不参与合并**：空名短路不映射，无主不会被写成有主，
  无主物另列且不计入物主人数。
- 合并、上架、借出都走 `BEGIN IMMEDIATE` 写事务串行执行：合并进行中即便有人按旧名
  上架、另一人按新名借出同一件，也不会出现一户两挂，或可借栏已空而在借行仍挂旧户。
- 合并校验失败（同名 / 空名 / 旧名已被并 / 两户都不存在）整笔回滚，人数与物主列
  回到点击之前。

接口：`GET /api/owners`、`POST /api/owners/merge`。
